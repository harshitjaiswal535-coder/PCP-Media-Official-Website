PCP MEDIA WEBSITE — STATIC VERSION

FILES
- index.html: Home page
- about.html: About us page
- services.html: Services page with sections and FAQ accordions
- contact.html: Contact page with WhatsApp/email links and direct enquiry submission
- styles.css: Shared design system and responsive layouts
- script.js: Mobile navigation and direct email-form submission

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a browser. For best results, use a local static server or publish the folder to a static host.
3. Keep all HTML files, styles.css and script.js together in the same folder.

ENQUIRY FORM EMAIL DELIVERY
- Both enquiry forms submit to pcpmedia001@gmail.com through FormSubmit, without opening Gmail or Outlook.
- On the first live submission, FormSubmit may send an activation/confirmation email to the destination inbox. Confirm it before relying on delivery.
- FormSubmit is a third-party service; review its privacy and spam-protection settings before publishing.

CUSTOMISE
- Replace the stock photo URLs in the HTML with your own licensed images or image URLs.
- Update WhatsApp number and email in the HTML if they change.
- The contact forms use the FormSubmit email delivery service and need an internet connection to submit.

NOTES
- This is an independent static recreation based on the screenshots supplied by the user, not an export of the Framer project.
- The design is responsive and includes five separate pages.
- Portfolio entries are labelled as self-initiated concept projects; they should not be presented as client work unless that is accurate.

UPDATING CLIENT TESTIMONIALS
Open index.html and search for id="testimonial-track". Inside it, duplicate an existing <article class="testimonial-card">...</article> block and change the quote, initials, name and company. Save the file. The testimonials area scrolls horizontally, and the arrow buttons move one card at a time. Keep testimonials accurate and get permission before publishing client quotes/names.

HOMEPAGE PROJECT ENQUIRY
